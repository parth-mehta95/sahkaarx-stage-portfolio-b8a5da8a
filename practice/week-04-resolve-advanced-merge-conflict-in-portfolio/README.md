# Resolve Advanced Merge Conflict in Portfolio

## Task Brief
Create conflicting branches, resolve merge conflicts, and document the resolution in your portfolio repository.

## Scenario
Two team members modify the same file. Create branches that conflict, resolve the conflict manually, and merge successfully into main.

## Deliverables
- Resolved merge conflict in repo
- Commit explaining resolution

## Success Criteria
- Conflict markers resolved correctly
- Merge commit message explains resolution
