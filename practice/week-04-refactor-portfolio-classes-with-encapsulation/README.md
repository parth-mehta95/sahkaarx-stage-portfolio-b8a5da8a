# Refactor Portfolio Classes with Encapsulation

## Task Brief
Add private fields, public accessors, and constructors to all portfolio classes; enforce access control and validate object state.

## Scenario
Your team requires all portfolio classes to enforce encapsulation and proper initialization before production deployment.

## Deliverables
- Refactored classes with private fields
- Public accessor methods

## Success Criteria
- All fields are private with public getters/setters
- Constructors validate object state
