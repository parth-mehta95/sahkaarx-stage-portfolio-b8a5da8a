# Refactor Portfolio Classes with Constructors and Encapsulation

## Task Brief
Add private fields, public accessors, constructors, and validation to all portfolio classes; enforce access control.

## Scenario
Your team needs to enforce encapsulation and add proper initialization to portfolio collection classes.

## Deliverables
- Updated LinkedList and ArrayList with constructors
- Private fields with public accessors

## Success Criteria
- All classes have parameterized constructors
- Private fields cannot be accessed directly
