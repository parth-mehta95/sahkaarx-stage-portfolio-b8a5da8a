# Resolve Complex Merge Conflicts in Portfolio

## Task Brief
Intentionally create conflicting branches, resolve merge conflicts, document resolution, and merge into main.

## Scenario
Two team members edited the same file. Resolve the conflict and merge both changes cleanly.

## Deliverables
- Conflicting branches in repository
- Resolved merge conflict in code
- Merged result in main branch

## Success Criteria
- Conflict markers resolved correctly
- Both changes preserved where applicable
- Clean commit history after merge
