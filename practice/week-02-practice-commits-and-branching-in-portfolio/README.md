# Practice Commits and Branching in Portfolio

## Task Brief
Execute atomic commits with clear messages and establish feature branch naming conventions for your portfolio.

## Scenario
Implement professional commit practices and branching strategy in your portfolio repository.

## Deliverables
- Feature branches with clear naming
- Atomic commits with descriptive messages
- CONTRIBUTING guide with branching rules

## Success Criteria
- Commits follow conventional format
- Branch names follow feature/bugfix pattern
- CONTRIBUTING documents team workflow
