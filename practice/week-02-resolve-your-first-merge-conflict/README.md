# Resolve Your First Merge Conflict

## Task Brief
Intentionally create and resolve a merge conflict scenario in your portfolio repository to practice conflict resolution.

## Scenario
Two branches modify the same file. Merge them, resolve the conflict, and document the resolution process.

## Deliverables
- Resolved merge conflict in portfolio repo
- Commit message explaining resolution

## Success Criteria
- Conflict markers identified and resolved correctly
- Merged branch contains both feature changes
