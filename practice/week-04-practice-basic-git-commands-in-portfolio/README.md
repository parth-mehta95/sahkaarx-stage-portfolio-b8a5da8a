# Practice Basic Git Commands in Portfolio

## Task Brief
Execute add, commit, push, pull, and status commands to manage your portfolio repository workflow.

## Scenario
Your team reviews your repository. Demonstrate proficiency with core Git commands by making updates, committing changes, and pushing to GitHub.

## Deliverables
- Multiple commits with clear messages
- Clean git status output

## Success Criteria
- At least 3 new commits with descriptive messages
- git status shows clean working tree
